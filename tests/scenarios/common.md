# 공통 시나리오

형식: 시나리오마다 `## <ID> <제목>` / `상황:` / `어머니 말:` (턴별) / `통과 조건:` (체크 가능한 문장 목록).
드라이런: 진행자 에이전트는 해당 스킬(SKILL.md + references)만 받고 GPT 역할을 한다. 판정자 에이전트는 대화와 통과 조건만 보고 판정한다.
공통 시나리오는 mom-0-start에 대고 돌린다.

## R1 문서 폴더가 OneDrive로 옮겨진 PC
상황: 강의 0 첫 시작. PowerShell `[Environment]::GetFolderPath('MyDocuments')` 결과가 `C:\Users\kim\OneDrive - 한빛상사\문서`. 진도 파일은 없음.
어머니 말:
1. "엄마 강의"
2. "응 처음이야"
통과 조건:
- 진도 파일을 `C:\Users\kim\OneDrive - 한빛상사\문서\엄마강의\진도.md`에 만든다 (또는 만들겠다고 한다).
- `C:\Users\kim\Documents`를 하드코딩해서 쓰지 않는다.
- 어머니께 경로 문자열을 그대로 읽어주지 않고 "문서 폴더 안 엄마강의 폴더"처럼 말한다.

## R2 "했어"라고 했지만 실제로는 안 됨
상황: 강의 0 블록 1(권한). 어머니가 붙인 캡처에 권한 버튼이 "Ask for approval"로 보인다.
어머니 말:
1. "했어" (캡처 첨부: 권한 버튼에 Ask for approval)
통과 조건:
- 통과시키지 않는다. 블록 2로 넘어가지 않는다.
- 지금 "Ask for approval"로 되어 있다는 한 가지 차이를 말한다.
- Full access로 바꾸는 단계를 다시 번호로 안내하고 "했어"를 요청하며 멈춘다.

## R3 블록 중간의 엉뚱한 질문
상황: 강의 0 블록 5(캡처) 첫 턴이 끝난 상태.
어머니 말:
1. "근데 이거 회사 사람들도 다 볼 수 있는 거야?"
통과 조건:
- 질문에 2~3문장으로 답한다 (대화는 어머니 계정에 저장된다는 취지. 회사 관리 여부처럼 확실하지 않은 부분은 확실하지 않다고 해도 된다).
- 블록 5의 해보기로 돌아와 "했어"를 다시 요청한다.
- 블록 6 내용을 시작하지 않는다.
