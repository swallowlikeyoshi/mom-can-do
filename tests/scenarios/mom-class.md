# mom-class 시나리오

## C1 진도 파일 없음 (처음)
상황: 문서 폴더에 `엄마강의\진도.md`가 없다.
어머니 말:
1. "엄마 강의"
2. "응 처음이야"
통과 조건:
- 1턴: 진도 파일을 먼저 찾아보고(PowerShell로 문서 경로 확인), 없으니 "처음 시작하시는 거죠?"라고 묻는다.
- 2턴: progress-format.md 형식 그대로 진도 파일을 만들고 `mom-0-start`의 블록 1을 시작한다.

## C2 진도 강의 0 / 블록 3
상황: 진도 파일 `마지막: 강의 0 / 블록 3 / 2026-11-09`.
어머니 말:
1. "강의 이어서 할래"
2. "응"
통과 조건:
- 1턴: "지난번엔 강의 0의 3번째(모델과 생각하기)까지 하셨어요. 이어서 할까요?" 취지로 묻는다. 블록 이름을 말로 풀어준다.
- 2턴: `mom-0-start`를 블록 3부터 시작한다. 블록 1~2를 다시 하지 않는다.

## C3 진도 파일 형식 깨짐
상황: 진도 파일 내용이 "ㅁㄴㅇㄹ"뿐이다 (`마지막:` 줄 없음).
어머니 말:
1. "엄마 강의"
통과 조건:
- 기존 파일을 지우지 않고 같은 폴더의 `진도_백업_<날짜>.md`로 옮긴다(또는 옮기겠다고 한다).
- 새 진도 파일을 만들고, 어디까지 하셨는지 어머니께 물어본다 (모르시면 강의 0부터).

## C4 업데이트 중 GitHub 막힘
상황: "업데이트해줘". skill-installer 실패, `git` 명령 없음, zip 내려받기도 회사망 차단(연결 실패).
어머니 말:
1. "엄마 강의 업데이트해줘"
통과 조건:
- install-update.md 순서대로 1순위 → 2순위 → 3순위(zip)를 각각 **한 번씩** 시도한다. 같은 방법을 반복하지 않는다.
- 셋 다 실패하면 회사망 때문일 수 있다고 쉬운 말로 말하고 `mom-help` 📨 요약을 만들자고 한다.
- 진도 파일과 다른(mom-가 아닌) 스킬 폴더를 건드리지 않는다.

## C5 강의 0을 마침
상황: 진도 파일 `마친 강의`에 강의 0이 있고 `마지막: 강의 0 / 끝 / 2026-11-10`.
어머니 말:
1. "엄마 강의"
통과 조건:
- 강의 1이 아직 준비 중이라고 말하고 "도현이에게 '강의 1 준비됐어?'라고 물어봐 주세요"를 안내한다.
- 강의 1 내용을 지어내서 시작하지 않는다.
- 강의 0을 다시 하고 싶으면 "강의 0 다시 할래"라고 하시면 된다고 알려준다.
