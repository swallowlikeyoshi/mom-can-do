# mom-0-start 시나리오

## S1 처음부터 끝까지 정상 진행
상황: mom-class가 진도 파일을 새로 만들고 강의 0 블록 1부터 시작. 어머니는 매번 제대로 하고 캡처를 붙인다. 모델 목록 캡처에는 "6 Luna, 5.6 Terra, 5.6 Luna"와 Think 버튼이 보인다.
어머니 말: 블록마다 (필요하면 캡처와 함께) "했어", 블록 3의 비교 뒤엔 "켜니까 더 길고 자세해", 블록 6에선 새 채팅에서 받은 답 한 줄을 붙여 넣음.
통과 조건:
- 블록마다 첫 턴이 "했어" 요청으로 끝나고 그 뒤에 다른 내용(확인 질문, 다음 블록 예고)이 없다.
- 블록 순서가 1 권한 → 2 개인 정보 → 3 모델과 생각하기 → 4 캡처 → 5 강의 부르기 → 6 새 채팅이다.
- 블록 2에서 "주민번호, 비밀번호, 계좌번호 같은 개인 정보만 빼고 넣어요" 문장이 나오고, 회사 이야기는 넣어도 된다고 말한다.
- 블록 3에서 어머니 캡처에 보인 모델 이름(6 Luna 등)을 그대로 써서 "평소엔 / 틀리면 안 되는 일엔"을 설명한다. 스킬에 없는 모델 이름을 지어내지 않는다.
- 블록이 시작될 때마다 진도 `마지막:` 줄을 갱신한다.

## S2 Think 버튼이 없음
상황: 블록 3. 어머니 캡처에 모델 이름 목록만 있고 Think 버튼은 안 보인다.
어머니 말:
1. "했어" (캡처 첨부)
통과 조건:
- Think 비교 실습을 강요하지 않고, 보이는 모델들 중에서 고르는 법으로 설명을 바꾼다.
- 멈추거나 오류로 다루지 않고 블록을 진행한다 (필요하면 같은 질문을 두 모델로 비교).

## S3 블록 4부터 재개
상황: mom-class가 "블록 4부터"로 넘김.
어머니 말:
1. (없음, 스킬 시작)
통과 조건:
- 블록 4(화면 캡처)의 첫 턴으로 시작한다. 블록 1~3 내용을 다시 하지 않는다.
- 이어서 한다는 걸 한 문장으로 알려준다.

## S4 블록 2 도중 "그만"
상황: 블록 2 첫 턴이 끝난 상태.
어머니 말:
1. "오늘은 여기까지 할래"
통과 조건:
- 진도 `마지막:` 줄이 `강의 0 / 블록 2 / <오늘>`이 되게 한다.
- "다음에 '엄마 강의'라고 하시면 여기서 이어서 해요"를 말하고 끝낸다.

## S5 강의 끝
상황: 블록 6 확인 통과.
어머니 말:
1. "했어"
통과 조건:
- ✅ 확인 기준 목록을 다시 보여준다.
- 노션 복습 링크 `https://app.notion.com/p/41379c82c6b68116a28ee4957fdb07ea`를 알려준다.
- 진도에 `마친 강의`로 강의 0을 적고 `마지막:`을 `강의 0 / 끝 / <오늘>`로 바꾼다.
- 다음에 "엄마 강의"라고 하시면 된다고 알려준다.
