# 최종 검토 지적 시나리오 (2026-11-10)

## F1 업데이트: git으로 받아 복사 (검토 C1, Minor 7)
상황: "엄마 강의 업데이트해줘". skill-installer는 없음/실패. `git --version` 성공. 각 PowerShell 명령은 **새 프로세스에서 따로** 실행됨(변수가 다음 명령으로 넘어가지 않음).
어머니 말:
1. "엄마 강의 업데이트해줘"
통과 조건:
- 내려받기와 복사를 **한 번의 PowerShell 실행**(한 블록) 안에서 한다. 앞 명령에서 만든 변수를 다음 명령에서 쓰지 않는다.
- 복사 전에 받은 폴더에 `mom-class\SKILL.md`가 있는지 확인한다.
- 복사된 폴더 이름을 출력하고, 0개면 성공이라고 하지 않는다.

## F2 블록 1: 캡처 없이 "Full access라고 보여" (검토 I1)
상황: 강의 0 블록 1 첫 턴이 끝난 상태. 실제 권한은 Ask for approval. GPT가 파일을 쓰려 하자 승인 창이 떴고 어머니가 허용을 눌러 파일이 써졌다.
어머니 말:
1. "Full access라고 보여" (캡처 없음)
2. "응 허용 눌렀어"
통과 조건:
- 파일이 써졌다는 것만으로 통과시키지 않는다.
- "방금 허용할지 묻는 창이 떴나요?" 같은 질문을 한다.
- 2턴: 창이 떴다고 하셨으니 아직 Full access가 아니라고 말하고 블록 1 해보기를 다시 안내한다. 블록 3로 넘어가지 않는다.

## F3 진도 파일 읽기·쓰기 인코딩 (검토 I2)
상황: 진도 파일 `마지막: 강의 0 / 블록 4 / 2026-11-09` (UTF-8, BOM 없음). Windows PowerShell 5.1.
어머니 말:
1. "엄마 강의"
통과 조건:
- 진도 파일을 읽는 도구 호출에 UTF-8을 명시한다 (`-Encoding UTF8` 또는 `[IO.File]::ReadAllText(..., [Text.Encoding]::UTF8)` 등).

## F4 다시 한 강의 뒤 다음 강의 고르기 (검토 I4)
상황: 설치된 스킬: mom-class, mom-0-start, mom-1-stuck, mom-2-ask, mom-help. 진도 파일:
```
# 엄마 강의 진도
마지막: 강의 0 / 끝 / 2026-11-10
## 마친 강의
- 강의 0 준비 운동 (2026-11-01)
- 강의 1 막혔을 때 혼자 푸는 법 (2026-11-03)
- 강의 2 GPT에게 제대로 부탁하는 법 (2026-11-05)
- 강의 0 준비 운동 (2026-11-10)
```
어머니 말:
1. "엄마 강의"
통과 조건:
- 다음 강의를 강의 3으로 본다 (강의 1로 보내지 않는다).
- 강의 3은 설치되어 있지 않으니 준비 중이라고 안내한다.

## F5 블록 중간의 "안 돼" (검토 I5)
상황: 강의 0 블록 5(화면 캡처) 첫 턴이 끝난 상태. 설치된 스킬: mom-class, mom-0-start, mom-help.
어머니 말:
1. "안 돼, 안 붙어"
통과 조건:
- "무엇을 하려던 중이셨어요?" 같은 🆘 인터뷰를 시작하지 않는다.
- 블록 5의 확인 절차대로 흔한 이유 하나를 말하고 해보기를 다시 안내하며 "했어"를 요청한다.

상황: 강의 0 블록 6 첫 턴이 끝난 상태. 진도 `마지막: 강의 0 / 블록 6 / 2026-11-10`.
