# 블록 1: 권한 설정

## 설명
- 인터넷 창에서 쓰던 ChatGPT는 **말만** 할 수 있었어요. 이 앱은 달라요. 어머니 컴퓨터의 **파일을 직접 열고, 고치고, 만들 수** 있어요. 나중에는 대신 클릭도 해요.
- 비유하면 GPT에게 **사무실 열쇠**를 주는 거예요. 열쇠를 안 주면, 서랍 하나 열 때마다 "열어도 될까요?" 하고 문 앞에서 물어봐요.
- 처음 설정 그대로면 정말 그래요. 일할 때마다 "해도 될까요?" 창이 떠요. 무엇을 허락해야 할지 판단하기 어렵고 번거롭기만 해요.
- 그래서 권한을 **가장 넓은 것**(GPT가 매번 묻지 않고 바로 하는 설정, 영어 화면에서는 "Full access")으로 바꿔요. 대신 약속은 하나예요: **연습은 복사본으로, 실제 업무 파일은 백업해 두고 시키기.** (백업 = 파일을 복사해서 하나 더 만들어 두는 것. 잘못돼도 원래 파일이 남아요.)
- 화면 맨 위나 옆에 모드를 고르는 곳(영어 화면에서는 "Chat / Work")이 보이면, 지금 이 강의처럼 컴퓨터 일을 시킬 때는 **작업(Work)** 쪽이라고 한 줄만 알려드려요. 정확한 이름은 캡처를 보고 맞춰 말해요.

## 해보기
1. 이 대화창의 **입력창 바로 아래**를 보세요. 권한을 고르는 버튼이 있어요 ("승인", "허용", "접근" 같은 글자가 들어 있을 거예요).
2. 그 버튼을 누르면 목록이 나와요. 그중에서 **"전체"**가 들어간 것, 또는 "묻지 않고 다 한다"는 뜻의 것을 고르세요 (영어 화면이면 "Full access"). 어느 건지 헷갈리시면 고르지 말고 목록을 캡처해서 보여주세요.
3. 확인 창이 뜨면 읽어보시고 허용을 누르세요.
4. 입력창 아래가 보이게 화면을 캡처해서 여기에 붙여 주세요. (캡처 방법: **Windows 키 + Shift + S**를 같이 누르고, 마우스로 입력창 근처를 끌어서 고른 뒤, 이 대화창을 누르고 **Ctrl + V**) 캡처는 블록 5에서 제대로 배우니까, 지금 어려우시면 버튼에 보이는 글자를 그대로 적어 주셔도 돼요.
5. 다 하시면 **'했어'** 라고 말해주세요.

## 확인
- 캡처가 있으면 권한 버튼이 **가장 넓은 권한**(영어로 Full access, 한글이면 "전체"가 들어간 이름)인지 봐요. 묻고 하는 쪽(영어로 Ask for approval, Approve for me, 한글이면 "승인", "확인" 같은 이름)이면 통과시키지 않고, 지금 무엇으로 되어 있는지 캡처의 글자 그대로 말한 뒤 해보기 2~4를 다시 안내해요. 목록 캡처를 받았으면 어느 것을 누르시면 되는지 그 글자로 짚어 드려요. 이 블록에서 확인한 실제 이름은 진도 파일 맨 아래에 `화면 이름: 권한 = <글자>`로 적어 둬요.
- 캡처 없이 글자로만 알려주시면, 작은 파일 하나를 바로 만들어 보는 것으로 확인해요: 문서 폴더 안 `엄마강의` 폴더에 `권한확인.txt`를 만들고 "확인" 한 줄을 써요. 파일을 만든 뒤 **꼭 물어봐요**: "방금 '허용할까요?' 같은 창이 떴나요?" "아니"면 통과하고 그 파일은 지워요. "응"이나 "허용 눌렀어"면 아직 Full access가 아니라고 말하고 해보기 1~4를 다시 안내해요. 파일이 만들어졌다는 것만으로는 통과시키지 않아요.
- 회사 보안 때문에 가장 넓은 권한을 고를 수 없으면(버튼이 회색, 관리자 정책 문구): 우회하지 않아요. 진도 `건너뛴 블록`에 적고, "괜찮아요, 아들에게 나중에 물어봐요"라고 한 뒤 블록 2로 가요. 강의 끝에 `mom-help` 📨를 권해요.
