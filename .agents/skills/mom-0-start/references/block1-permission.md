# 블록 1: 권한 설정

## 설명
- 이 앱은 대화만 하는 게 아니라, 어머니 컴퓨터의 파일을 열고 고치고, 나중에는 대신 클릭도 할 수 있어요.
- 그런데 처음 설정 그대로면 GPT가 일할 때마다 "해도 될까요?"를 물어요. 무엇을 허락해야 할지 판단하기 어렵고 번거롭기만 해요.
- 그래서 **Full access**(GPT가 매번 묻지 않고 바로 하는 설정)로 바꿔요. 대신 약속은 하나예요: **연습은 복사본으로, 실제 업무 파일은 백업해 두고 시키기.**
- 화면 맨 위나 옆에 **Chat / Work** 같은 모드 이름이 보이면, 지금 이 강의처럼 컴퓨터 일을 시킬 때는 **Work** 쪽이라고 한 줄만 알려드려요. 보이는 이름이 다르면 캡처를 보고 맞춰 말해요.

## 해보기
1. 이 대화창의 **입력창 바로 아래**를 보세요. 권한을 고르는 버튼이 있어요 (지금은 "Ask for approval" 같은 글자일 수 있어요).
2. 그 버튼을 누르고 **Full access**를 고르세요.
3. 확인 창이 뜨면 읽어보시고 허용을 누르세요.
4. 입력창 아래가 보이게 화면을 캡처해서 여기에 붙여 주세요. (캡처 방법: **Windows 키 + Shift + S**를 같이 누르고, 마우스로 입력창 근처를 끌어서 고른 뒤, 이 대화창을 누르고 **Ctrl + V**) 캡처는 블록 4에서 제대로 배우니까, 지금 어려우시면 "Full access라고 보여"라고 글로 쓰셔도 돼요.
5. 다 하시면 **'했어'** 라고 말해주세요.

## 확인
- 캡처가 있으면 권한 버튼에 **Full access**가 보이는지 봐요. "Ask for approval"이나 "Approve for me"면 통과시키지 않고, 지금 무엇으로 되어 있는지 말한 뒤 해보기 2~4를 다시 안내해요.
- 캡처 없이 "Full access라고 보여"라고 하시면, 작은 파일 하나를 바로 만들어 보는 것으로 확인해요: 문서 폴더 안 `엄마강의` 폴더에 `권한확인.txt`를 만들고 "확인" 한 줄을 써요. 파일을 만든 뒤 **꼭 물어봐요**: "방금 '허용할까요?' 같은 창이 떴나요?" "아니"면 통과하고 그 파일은 지워요. "응"이나 "허용 눌렀어"면 아직 Full access가 아니라고 말하고 해보기 1~4를 다시 안내해요. 파일이 만들어졌다는 것만으로는 통과시키지 않아요.
- 회사 보안 때문에 Full access를 고를 수 없으면(버튼이 회색, 관리자 정책 문구): 우회하지 않아요. 진도 `건너뛴 블록`에 적고, "괜찮아요, 아들에게 나중에 물어봐요"라고 한 뒤 블록 2로 가요. 강의 끝에 `mom-help` 📨를 권해요.
