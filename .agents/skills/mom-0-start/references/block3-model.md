# 블록 3: 모델과 생각하기

## 설명
- **모델**은 "누구에게 맡길지"예요. 빠르고 가벼운 모델은 간단한 일에, 큰 모델은 복잡한 일에 맞아요.
- **생각하기(Think)**는 "답하기 전에 얼마나 오래 생각할지"예요. 끄면 빠르지만 대충, 켜면 느리지만 꼼꼼해요.
- 어머니 화면에 무엇이 보이는지는 요금제마다 달라요. 그래서 먼저 어머니 화면을 같이 볼게요.

## 해보기
1. 입력창 근처(보통 위쪽이나 아래쪽)에서 **모델 이름**이 적힌 곳을 누르세요. 목록이 펼쳐져요.
2. 펼쳐진 목록이 보이게 캡처해서 여기에 붙여 주세요. 옆에 **생각하기**(영어 화면이면 Think) 같은 버튼이 있으면 그것도 같이 찍어 주세요.
3. 다 하시면 **'했어'** 라고 말해주세요.

## 확인 (2단계로 진행)
**① 목록 보고 설명하기** — 캡처에 보이는 이름을 **그대로** 써서 설명해요. 스킬에 없는 이름을 지어내지 않아요.
- 보이는 모델들을 "빠른 쪽 / 꼼꼼한 쪽"으로 나눠서 한 줄씩 말해요. 어느 쪽인지 확실하지 않으면 이름의 숫자가 크거나 설명에 "생각", "추론", "복잡한 작업"이 있는 쪽을 꼼꼼한 쪽으로 봐요.
- 고르는 법은 이렇게 정리해 드려요:
  - 메일 초안, 문장 다듬기처럼 **간단한 일** → 기본 그대로
  - 엑셀 수식, 숫자 맞추기, 여러 파일 정리처럼 **틀리면 안 되는 일** → 꼼꼼한 모델이나 **생각하기 켜기**
- 그다음 비교 실습을 안내하고 멈춰요:
  1. 이 대화에서 그대로 하세요. 생각하기를 **끈 채로** "부가세 신고는 언제 하고, 뭘 준비해야 해?"라고 보내세요.
  2. 생각하기를 **켜고** 같은 질문을 한 번 더 보내세요.
  3. 두 답이 어떻게 달랐는지 한 줄로 말해주세요.
- Think 버튼이 **없으면**: 1~2를 "빠른 쪽 모델로 한 번, 꼼꼼한 쪽 모델로 한 번"으로 바꿔요. 모델도 하나뿐이면 비교 실습은 건너뛰고, 고르는 법만 정리한 뒤 통과예요. 이건 오류가 아니라 요금제 차이라고 말해드려요.

**② 비교 확인** — 어머니가 차이를 한 줄로 말하시면 통과예요 (어떤 차이든 괜찮아요). "켜니까 더 길고 자세해"처럼 말씀하시면 "맞아요, 그래서 틀리면 안 되는 일엔 켜는 거예요"로 연결해요.
- 진행하는 GPT(나) 자신의 모델이나 설정은 바꾸지 않아요. 비교 질문에 대한 답은 어머니가 보내신 대로 그냥 답해요.
