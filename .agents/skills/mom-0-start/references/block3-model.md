# 블록 3: 모델과 생각하기

> 이 블록은 두 단계예요. **① 지금 있는 모델과 고르는 법 알기 → ② 같은 질문을 두 가지로 해보고 비교하기.** 각 단계가 2턴 규칙을 따라요.

## 설명 (① 첫 턴에 그대로 풀어서 전해요)

**모델이 뭐예요?**
- ChatGPT 안에는 **일하는 직원이 여러 명** 있다고 생각하시면 돼요. 그 직원 하나하나를 "모델"이라고 불러요.
- 빠르게 척척 대답하는 직원도 있고, 조금 느리지만 꼼꼼하게 따져보는 직원도 있어요. 일에 맞게 골라 쓰면 돼요.

**이름 읽는 법**
- 모델 이름은 **숫자 + 등급**이에요. 예: "6 Luna"
- **숫자**는 몇 번째로 나온 직원인지예요. 숫자가 클수록 **최신**이에요. (6이 5.6보다 새것)
- **등급**은 이름 뒤에 붙은 영어예요. 아래로 갈수록 똑똑해요.

| 등급 | 읽는 법 | 특징 | 어머니 요금제(Go)에서 |
|---|---|---|---|
| Luna | 루나 (달) | 가장 빠르고 가벼워요 | ✅ 있어요 |
| Terra | 테라 (지구) | 한 단계 위. 조금 느리지만 더 꼼꼼해요 | ✅ 있어요 |
| Sol | 솔 (태양) | 더 똑똑해요 | ❌ 비싼 요금제(Plus 이상)만 |
| Astra | 아스트라 (별) | 가장 똑똑해요 | ❌ 비싼 요금제만 |

**어머니가 지금 고르시면 되는 것** (2026년 11월, 아들이 확인한 화면 기준)

| 화면에 보이는 이름 | 언제 쓰나요 |
|---|---|
| **6 Luna** | **평소 기본.** 가장 새것이고 빨라요. 메일 쓰기, 문장 다듬기, 간단한 질문 |
| **5.6 Terra** | **틀리면 안 되는 일.** 엑셀 수식, 숫자 맞추기, 긴 공고문 읽기, 사업계획서 쓰기 |
| 5.6 Luna | 안 쓰셔도 돼요. 예전 가벼운 직원이에요 |

**생각하기 버튼**
- 화면에 따라 모델 목록 대신 **생각하기**(영어 화면이면 Think) 버튼만 있을 수 있어요. 특히 그냥 대화하는 모드(채팅)에서는 모델을 못 고르고 이 버튼만 있어요.
- 켜면 답하기 전에 더 오래 생각해요. 느리지만 꼼꼼해져요. **틀리면 안 되는 일엔 켜세요.**

**요령 하나**: 답이 이상하거나 마음에 안 들면, **다른 모델로 바꿔서 같은 질문을 다시** 해보세요. 그게 제일 쉬운 해결법이에요.

## 해보기 (① 첫 턴)
1. 입력창 근처(위쪽이나 아래쪽)에서 **모델 이름**이 적힌 곳을 찾아 누르세요. 지금은 아마 "6 Luna" 같은 글자가 보일 거예요. 누르면 목록이 펼쳐져요.
2. 펼쳐진 목록이 보이게 캡처해서 여기에 붙여 주세요. 옆에 **생각하기** 버튼이 있으면 그것도 같이 찍어 주세요.
3. 다 하시면 **'했어'** 라고 말해주세요.

## 확인 (① 둘째 턴 → ② 첫 턴)
**① 목록 확인**
- 캡처의 이름이 위 표와 **같으면**: 표의 세 줄을 어머니 화면의 위치와 함께 다시 짚어 드려요. "맨 위의 6 Luna가 평소용, 두 번째 5.6 Terra가 꼼꼼한 일용이에요."
- **다르면**: 캡처에 보이는 이름을 위의 **이름 읽는 법**(숫자가 크면 최신, Luna < Terra < Sol < Astra)으로 나눠서 "평소용 / 꼼꼼한 일용"을 정해 드려요. 이름을 지어내지 않아요. 판단이 어려운 이름은 "이건 저도 확실하지 않아요"라고 말하고 아는 것만으로 골라 드려요.
- **모델 목록이 없고 생각하기 버튼만** 있으면: "지금 화면에서는 모델을 고르는 대신 생각하기 버튼으로 조절해요"라고 말해요. 오류가 아니라 화면 차이예요.
- 진도 파일 맨 아래에 `화면 이름: 모델 = <캡처에 보인 이름들>`을 적어요.

**② 비교 실습** (이어서 안내하고 멈춰요)
1. 이 대화에서 그대로 하세요. 먼저 모델을 **평소용**(6 Luna)으로 두고 아래 질문을 보내세요:
   > 월급 300만 원인 직원의 4대 보험 회사 부담금이 대략 얼마인지 계산해 줘. 계산 과정도 보여줘.
2. 답을 받으면 모델을 **꼼꼼한 일용**(5.6 Terra)으로 바꾸고 **같은 질문**을 한 번 더 보내세요.
   - 모델 목록이 없으면: 생각하기를 **끄고 한 번, 켜고 한 번** 보내세요.
   - 모델도 하나뿐이고 생각하기 버튼도 없으면 이 비교는 건너뛰어요.
3. 두 답이 어떻게 달랐는지 한 줄로 말해주세요. ("두 번째가 더 자세해" 같은 것도 좋아요.)

**② 확인**
- 어머니가 차이를 한 줄로 말하시면 통과예요. 어떤 차이든 괜찮아요. "맞아요. 그래서 숫자 계산이나 중요한 글은 꼼꼼한 쪽으로 하는 거예요"로 연결해요.
- 두 답의 숫자가 서로 다르면 좋은 기회예요: "이렇게 답이 다를 수 있어요. 그래서 중요한 숫자는 꼭 확인해야 해요"라고 한 줄 덧붙여요.
- 마지막에 "평소엔 다시 **6 Luna**로 돌려 두세요"라고 안내해요.
- 비교 질문 자체에는 보내신 대로 그냥 답해요.
