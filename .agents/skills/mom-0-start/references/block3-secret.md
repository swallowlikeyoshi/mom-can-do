# 블록 3: 개인 정보 약속

## 설명
- 여기에 쓰는 내용은 어머니 계정에 저장되고, OpenAI 서버를 거쳐요.
- 회사 이야기는 편하게 하셔도 돼요. 대신 약속 하나만 해요. 짧은 블록이에요.

## 해보기
1. 아래 한 문장을 소리 내서 한 번 읽어 보세요.
   > 🔒 **주민번호, 비밀번호, 계좌번호 같은 개인 정보만 빼고 넣어요.**
2. 회사 매출이나 직원 수, 제품 이야기는 넣어도 괜찮아요. 나중에 사업계획서를 쓸 때 꼭 필요한 정보예요.
3. 알겠으면 **'알겠어'** 라고 말해주세요.

## 확인
- "알겠어"(또는 비슷한 대답)를 받으면 통과예요. 확인할 파일은 없어요.
- 이후 강의에서 계좌번호 같은 게 보여도 멈추지 않아요. 한 줄로만 다시 알려드려요 (공통 규칙).
