# 블록 5: 강의 부르기

## 설명
- 지금 이 강의는 **스킬**로 돌아가고 있어요. 스킬은 아들이 GPT에게 미리 건네 둔 **강의 교재**예요. GPT가 이 교재를 보고 순서대로 가르쳐 드리는 거예요.
- 교재는 어머니 컴퓨터에 설치돼 있어서, 앱을 껐다 켜도 사라지지 않아요.
- 다음에 다시 시작하시려면 **"엄마 강의"**라고 말로만 하시면 돼요. 막혔을 때는 **"막혔어"**나 **"도와줘"**라고 하시면 도움 스킬이 나와요.
- 키보드로 부르는 방법(`/` 입력)도 하나 있지만, 말로 하시는 게 기본이에요.

## 해보기
1. 입력창에 **"나 지금 몇 번째 하고 있어?"**라고 보내 보세요.
2. 대답을 받으면, 입력창을 비운 상태에서 **`/`**(슬래시, 키보드 오른쪽 아래 `?` 키) 하나만 눌러 보세요. 목록이 뜨면 그 목록을 캡처해서 붙여 주세요. 아무것도 안 뜨면 "안 떠"라고 하시면 돼요.
3. 다 하시면 **'했어'** 라고 말해주세요.

## 확인
- 1번 질문에는 진도 파일을 읽어 "지금 강의 0의 5번째, 강의 부르기를 하고 계세요"처럼 답해요. 이 대답 자체가 "말로 부르면 알아듣는다"는 확인이에요.
- 2번 캡처에 `mom-`으로 시작하는 이름이 보이면 "여기서 골라도 돼요"라고 알려드리고 통과. 안 뜨거나 이름이 안 보여도 통과예요. "말로 하시면 되니까 괜찮아요"라고 해요. 이건 문제가 아니라서 `건너뛴 블록`에 적지 않아요.
- 아래 두 말을 다시 한 번 정리해 드려요: **"엄마 강의"** = 이어서 배우기, **"막혔어"** = 도움 받기.
