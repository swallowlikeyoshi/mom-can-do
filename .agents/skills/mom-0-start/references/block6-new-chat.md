# 블록 6: 새 채팅 오가기

## 설명
- 강의 1부터는 창을 두 개 써요. 지금 이 대화는 **"선생님 창"**이에요. 설명을 듣고, 다 했는지 확인받는 곳이에요.
- 실습은 **새 채팅**에서 해요. 새 채팅의 GPT는 강의 내용을 모르는 "처음 만난 GPT"예요. 실제 업무에서 만나실 GPT도 그렇기 때문에, 거기서 연습해야 진짜 실력이 돼요.
- 오늘은 새 채팅을 열었다가 이 선생님 창으로 돌아오는 것만 해볼게요.

## 해보기
1. 화면 왼쪽 위의 **새 채팅**(연필 모양이나 "+ 새 채팅") 버튼을 누르세요.
2. 새 채팅 입력창에 **"안녕, 오늘 날씨 어때?"**라고 보내세요.
3. 답을 받으면, **화면 왼쪽 대화 목록**에서 이 대화(제목에 "엄마 강의"나 "준비 운동"이 들어간 것, 아니면 바로 아래 것)를 누르세요.
4. 여기로 돌아오셨으면, 새 채팅에서 받은 답의 **첫 줄**을 복사해서 붙여 주세요. (복사: 글자를 마우스로 긁고 **Ctrl + C**, 붙이기: **Ctrl + V**)
5. 그리고 **'했어'** 라고 말해주세요.

## 확인
- 어머니가 이 대화로 돌아와 새 채팅의 답 한 줄을 붙여 주셨으면 통과예요. 붙인 줄이 없으면 "돌아오신 건 잘하셨어요"라고 하고 4번만 다시 부탁해요.
- 이 대화를 못 찾으시면: 왼쪽 목록이 안 보일 때는 화면 왼쪽 위의 **목록 버튼(줄 세 개)**을 눌러야 해요. 목록 맨 위 근처에 있다고 알려드려요.
- 통과하면 한 줄로: "강의 1부터는 이렇게 **선생님 창 ↔ 새 채팅**을 오가요. 헷갈리시면 언제든 여기로 돌아와서 물어보세요."
