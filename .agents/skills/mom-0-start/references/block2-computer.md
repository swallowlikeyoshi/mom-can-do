# 블록 2: 컴퓨터 사용 켜기

> Windows에서는 켜는 단계가 조금 까다로워요. 한 단계씩 천천히 안내하고, 막히면 화면 캡처를 받아서 짚어 드려요. 버튼 이름은 영어 공식 이름을 예시로만 쓰고, 어머니 화면의 글자로 맞춰 말해요.

## 설명
- 블록 1에서 GPT에게 **파일을 다룰 열쇠**를 드렸어요. 이번엔 **화면을 보고 마우스를 대신 움직이는 기능**을 켜요. 이걸 "컴퓨터 사용"이라고 해요 (영어 화면이면 Computer use).
- 이걸 켜두면 좋은 점:
  - 앞으로 막혔을 때 어머니가 일일이 설명하거나 캡처하지 않아도, **GPT가 화면을 직접 보고** 무엇이 문제인지 알아봐요.
  - 앱 설정이 잘못돼 있으면 GPT가 직접 눌러서 고쳐 드릴 수도 있어요.
  - 나중에 엑셀처럼 다른 프로그램 일도 맡길 수 있어요.
- 꼭 알아두실 것 하나: GPT가 움직이는 동안엔 **진짜 마우스와 키보드**를 GPT가 써요. 그동안 어머니는 **손을 떼고 지켜보시면** 돼요. 직접 쓰고 싶으시면 화면의 **중지** 버튼을 먼저 누르세요.

## 해보기
1. 화면 위쪽에서 모드를 고르는 곳이 보이면 **작업** 쪽을 고르세요 (영어 화면이면 Work). 이미 그렇게 되어 있으면 그대로 두세요.
2. 앱 왼쪽 아래(또는 프로필 그림)를 눌러 **설정**을 여세요.
3. 설정 목록에서 **"컴퓨터"가 들어간 메뉴**를 누르세요 (영어 화면이면 Computer use).
4. 그 안에서 **"모든 앱"을 제어하게 하는 줄**을 찾으세요 (영어 화면이면 Control 아래 Any App). **설치** 버튼이 보이면 누르고, 스위치가 보이면 켜세요.
5. 설치하는 동안 Windows가 **"이 앱이 디바이스를 변경하도록 허용하시겠어요?"** 같은 창을 띄우면 **예**를 누르세요.
   - 이때 **관리자 암호**를 물어보면 더 하지 말고 멈추세요. 회사 컴퓨터라 전산 담당만 허락할 수 있는 경우예요.
6. 끝나면 이 대화로 돌아와서 **'했어'** 라고 말해주세요. 중간에 헷갈리면 그 화면을 캡처해서 붙여 주세요.

## 확인
- "했어"를 받으면 GPT가 **직접 시험**해요. 먼저 말해요: "제가 메모장을 열어서 '안녕'이라고 써볼게요. 끝날 때까지 마우스와 키보드에서 손을 떼 주세요."
  - 처음 프로그램을 쓸 때 **"메모장을 사용하도록 허용할까요?"** 같은 창이 뜰 수 있어요 (영어: Always allow / Allow / Cancel). 어머니께 "이 창의 **항상 허용** 버튼만 눌러 주시고, 다시 손을 떼 주세요"라고 안내해요. 이 버튼은 어머니만 누를 수 있어요.
  - 메모장에 '안녕'이 써지면: "됐어요! 이제 제가 화면을 볼 수 있어요. 메모장은 저장하지 않고 닫을게요." 하고 닫은 뒤, "다 됐어요, 이제 쓰셔도 돼요."로 끝내고 통과예요.
- 캡처가 오면 캡처의 글자로 어느 단계인지 짚어 드리고, 그 단계부터 다시 안내해요. 메뉴 이름이 "컴퓨터 사용"과 다르면 진도 파일 맨 아래에 `화면 이름: 컴퓨터 사용 = <메뉴 이름>`을 적어요.
- **안 되는 경우** (메뉴가 없음, 관리자 암호, 회사 보안 경고, 설치 실패):
  - 우회하지 않아요. "괜찮아요, 이건 나중에 아들과 같이 해요. 그동안은 캡처로 보여주시면 돼요."
  - 진도 파일 `## 건너뛴 블록`에 `- 강의 0 블록 2: <이유> (<날짜>)`를 적고 블록 3으로 가요.
  - 강의 끝에서 `mom-help` 📨를 권해요.
- 통과한 뒤 한 줄로 정리해요: "앞으로 막히면 '막혔어'라고만 하세요. 제가 화면을 보고 같이 찾아볼게요."
