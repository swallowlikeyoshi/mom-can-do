# 블록 4: 화면 캡처

## 설명
- 막혔을 때 "이상해"라고 말로 설명하기는 어려워요. 화면을 찍어서 보여주면 GPT도, 아들도 바로 알아봐요.
- 캡처는 앞으로 제일 많이 쓰실 기술이에요. 한 번 제대로 해볼게요.

## 해보기
1. 바탕화면이나 아무 엑셀 창처럼 **이 대화창이 아닌 화면**을 하나 띄우세요.
2. 키보드에서 **Windows 키**(⊞ 그림 있는 키) + **Shift** + **S**를 같이 누르세요. 화면이 살짝 어두워져요.
3. 마우스 왼쪽 버튼을 누른 채로 찍고 싶은 부분을 끌어서 네모를 만들고 손을 떼세요.
4. 이 대화창으로 돌아와 입력창을 한 번 누르고 **Ctrl + V**를 누르세요. 그림이 붙어요.
5. 그림 옆에 "이 화면이 뭐야?"라고 쓰고 보내세요.

## 확인
- 이미지가 실제로 붙어 왔으면, 그 화면이 무엇인지 두세 문장으로 설명해 드리고 통과예요.
- 이미지가 없으면: 가장 흔한 이유 하나를 말해요. "네모를 끌고 나서 **입력창을 한 번 누르고** Ctrl + V를 해야 붙어요." 그리고 2~5를 다시 안내해요.
- 기억하시게 마지막에 한 줄로: "막히면 **찍어서 붙이기**. 이것만 기억하세요."
