# 블록 2: 기밀 약속

## 설명
- 여기에 쓰는 내용은 어머니 계정에 저장되고, OpenAI 서버를 거쳐요.
- 그래서 약속 하나만 해요. 짧은 블록이에요.

## 해보기
1. 아래 한 문장을 소리 내서 한 번 읽어 보세요.
   > 🔒 **회사 기밀, 주민번호, 계좌번호는 넣지 마세요.**
2. 업무 파일을 맡길 때 이런 게 들어 있으면 그 칸을 지우거나 "***"로 바꾼 **복사본**을 쓰시면 돼요. 어떻게 하는지는 강의 3에서 같이 해요.
3. 알겠으면 **'알겠어'** 라고 말해주세요.

## 확인
- "알겠어"(또는 비슷한 대답)를 받으면 통과예요. 확인할 파일은 없어요.
- 이후 강의에서 계좌번호 같은 게 보여도 멈추지 않아요. 한 줄로만 다시 알려드려요 (공통 규칙).
