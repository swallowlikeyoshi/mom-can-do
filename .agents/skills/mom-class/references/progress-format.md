# 진도 파일 형식

위치: 문서 폴더(`[Environment]::GetFolderPath('MyDocuments')`) 안 `엄마강의\진도.md`. UTF-8로 저장해요.

새로 만들 때는 아래를 그대로 쓰고 날짜만 오늘로 바꿔요.

```
# 엄마 강의 진도
마지막: 강의 0 / 블록 1 / 2026-11-10
## 마친 강의
## 건너뛴 블록
## 내 목록
## 부탁문
```

## 규칙

- `마지막:` 줄은 항상 한 줄이고 형식은 `강의 <번호> / 블록 <번호> / <YYYY-MM-DD>`예요. 강의를 끝냈으면 블록 자리에 `끝`을 써요.
  - 블록이 **시작될 때** 그 블록 번호로 바꿔요. 그래서 중간에 그만두셔도 그 블록부터 다시 해요.
- 다음 강의는 `## 마친 강의`에 없는 가장 작은 번호예요. 다시 한 강의 때문에 `마지막:`이 앞 강의를 가리켜도 그걸로 정하지 않아요.
- `## 마친 강의`: 강의를 끝낼 때 `- 강의 0 준비 운동 (2026-11-10)` 한 줄을 더해요.
- `## 건너뛴 블록`: 회사 보안이나 앱 차이로 못 한 블록. `- 강의 0 블록 1: 회사 보안으로 전체 권한 안 됨 (2026-11-10)`.
- `## 내 목록`: 강의 3에서 쓰는 맡길 일 목록. 강의 0에서는 비워둬요.
- `## 부탁문`: 강의 4에서 저장한 부탁문 파일 이름 목록. 강의 0에서는 비워둬요.
- `화면 이름: <무엇> = <글자>` 줄: 강의 중 확인한 어머니 앱의 실제 버튼 이름(예: `화면 이름: 권한 = 전체 액세스`). 파일 맨 아래에 두고, 다음 강의에서 버튼을 안내할 때 이 글자를 써요.
- 깨진 파일(`마지막:` 줄이 없거나 형식이 다름): 지우지 말고 같은 폴더에 `진도_백업_<YYYY-MM-DD>.md`로 이름을 바꾼 뒤 새로 만들어요.

## 강의 번호와 스킬

| 강의 | 스킬 | 상태 |
|---|---|---|
| 0 준비 운동 | `mom-0-start` | 있음 |
| 1 막혔을 때 혼자 푸는 법 | `mom-1-stuck` | 준비 중 |
| 2 GPT에게 제대로 부탁하는 법 | `mom-2-ask` | 준비 중 |
| 3 내 일 하나 GPT에게 맡기기 | `mom-3-delegate` | 준비 중 |
| 4 다음번엔 한 번에 | `mom-4-save` | 준비 중 |
| 5 GPT에게 컴퓨터 맡기기 | `mom-5-computer` | 준비 중 |
| 6 졸업 과제 | `mom-6-graduate` | 준비 중 |

"준비 중"인지는 이 표보다 **실제로 설치된 스킬**을 믿어요 (`사용자폴더\.agents\skills\` 안에 그 폴더가 있는지).
