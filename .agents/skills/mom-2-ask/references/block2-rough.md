# 블록 2: 대충 부탁하기

## 설명
- 먼저 **대충** 부탁해 볼게요. 대부분 사람들이 처음에 이렇게 해요. 어떤 답이 나오는지 보는 게 목적이에요.
- 실습은 **새 채팅**에서 해요. 새 채팅의 GPT는 강의 내용을 모르는 "처음 만난 GPT"라서, 실제로 일할 때와 똑같아요.

## 해보기
1. 왼쪽 위 **새 채팅**을 누르세요. 그러면 빈 대화가 열려요.
2. 입력창 옆 **클립(📎) 또는 + 버튼**을 눌러 `엄마연습` 폴더의 **연습2_공고문**을 올리세요. 그러면 입력창 위에 파일이 붙어요.
3. **"이거 요약해줘"** 딱 이렇게만 쓰고 보내세요.
4. 답이 나오면 답 전체를 마우스로 긁어 **Ctrl + C**로 복사하세요.
5. 이 선생님 창으로 돌아와 **Ctrl + V**로 붙여 주세요.

붙여 주시면 그걸로 '했어'예요.

## 확인
- [answer-key.md](answer-key.md)의 7항목과 대조해 **"7개 중 ○개"**로 말해요. 빠진 항목을 다 불러주지는 않고, 하나만 예로 들어요: "예를 들어 '누가 신청 못 하는지'가 빠졌어요."
- 7개 다 있어도 솔직히 말하고 넘어가요: "이번엔 운이 좋았어요. 그런데 매번 이렇게 나오진 않아요. 매번 나오게 하는 방법을 해볼게요."
- 새 채팅이 강의를 이어서 하려고 하면("엄마 강의를 이어서 할까요?" 같은 말): "그건 새 채팅이 헷갈린 거예요. 새 채팅을 하나 더 열고, 파일을 올린 뒤 '이거 요약해줘'만 보내 주세요. '엄마 강의'라는 말은 쓰지 마세요." 그래도 또 강의를 시작하면 "강의 말고, 이 파일만 요약해줘"라고 보내시게 해요. 그리고 다시 결과를 기다려요.
