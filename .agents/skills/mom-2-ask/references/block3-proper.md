# 블록 3: 제대로 부탁하기

## 설명
- 제대로 부탁하는 데는 **네 가지**만 있으면 돼요. 새로 온 직원한테 일을 맡길 때와 똑같아요.
  1. **상황**: 이게 뭔지 ("이건 지원사업 공고문이야. 우리 회사가 신청할 수 있는지 보려고 해.")
  2. **원하는 결과**: 무엇을 뽑아 달라는지 ("신청 자격, 못 하는 경우, 돈, 기간, 서류, 점수 매기는 법, 문의처")
  3. **예시**: 어떤 모양으로 ("| 항목 | 내용 | 표로")
  4. **모르면 물어봐줘**: ("헷갈리는 게 있으면 만들기 전에 나한테 먼저 물어봐줘")
- 이 네 가지를 어머니가 **직접** 써 보세요. 제가 대신 써 드리면 어머니 실력이 안 늘어요.

## 해보기
1. 아래 회색 상자 오른쪽 위의 **복사** 버튼을 누르고, 이 선생님 창 입력창에 **Ctrl + V**로 붙인 다음, 괄호 뒤 빈칸을 어머니 말로 채워 주세요.
   ```
   (상황) 
   (원하는 결과) 
   (예시) 
   (모르면 물어봐줘) 
   ```
2. 채운 걸 여기 보내 주시면, 새 채팅에 보내기 전에 네 가지가 다 있는지 먼저 봐 드릴게요.

채워서 보내 주시면 그걸로 '했어'예요.

## 확인 (2단계)
**① 부탁 확인**
- 네 가지가 다 있으면: 구체적으로 칭찬하고("'| 항목 | 내용 |' 표 예시까지 넣으셨네요!") 다음을 안내하고 멈춰요:
  1. **새 채팅**을 하나 더 여세요(블록 2 채팅 말고 새로).
  2. 공고문 파일을 올리세요.
  3. 방금 쓴 부탁을 그대로 붙여서 보내세요. 괄호 표시는 그대로 둬도 괜찮아요.
  4. GPT가 되물으면 답해 주세요.
  5. 결과를 복사해 여기 붙여 주세요.
- 빠진 게 있으면 **하나만** 짚고 짧은 예를 들어 줘요. 대신 완성본을 써 주지 않아요.

**② 결과 확인**
- [answer-key.md](answer-key.md)와 대조해 "7개 중 ○개"로 말해요. **6개 이상이면 통과.** 블록 2 결과와 나란히 비교해 줘요: "대충 부탁했을 땐 3개, 제대로 부탁하니 7개예요."
- 5개 이하면 어느 요소가 약했는지 하나만 짚고 ②를 다시 해요.
