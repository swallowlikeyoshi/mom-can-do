# 블록 4: 틀린 곳만 고치게 하기

## 설명
- GPT 답이 조금 틀렸을 때, 처음부터 다시 시키면 시간도 들고 잘 된 부분까지 바뀔 수 있어요.
- **틀린 곳만 콕 집어서** 말하면 돼요. 직원한테 "다 다시 해"가 아니라 "3번만 고쳐줘"라고 하는 것처럼요.

## 해보기
(먼저 GPT가 블록 3 결과에서 빠졌거나 덜 정확한 항목 하나를 고르고, 다 맞았으면 "7개 다 맞았어요. 연습으로 하나만 더 다듬어 볼게요"라고 한 뒤 "문의처에 전화번호도 넣기"처럼 작은 다듬을 거리 하나를 정해 알려 드려요. 블록 3 채팅은 "방금 네 가지로 부탁했던 채팅(두 번째로 연 것)"이라고 짚어 드려요.)
1. 블록 3에서 쓴 **그 새 채팅**으로 가세요.
2. **"○○만 고쳐줘"** 또는 **"○○도 넣어줘"**처럼 한 줄로 보내세요. 예: "문의처에 전화번호도 넣어줘."
3. 고쳐진 답을 복사해서 여기 붙여 주세요.

붙여 주시면 그걸로 '했어'예요.

## 확인
- 짚은 항목만 고쳐졌고 나머지는 그대로면 통과: "딱 그것만 고쳐졌죠? 이게 제일 빠른 방법이에요."
- 어머니가 처음부터 다시 시키셨으면: "잘못하신 거 아니에요, 그렇게 해도 돼요. 그런데 **틀린 곳만 말해도 돼요.** 예를 들면 '문의처만 고쳐줘' 이 한 줄이요. 그러면 잘 된 부분은 그대로 두고 그것만 고쳐 줘요." 고칠 문장은 **하나만** 예로 들고, 2~3번을 다시 해보시게 한 뒤 "했어"를 요청해요.
- 통과하면 블록 3의 잘 된 부탁을 **저장**해요: 문서 폴더 `엄마강의\부탁문\공고문_요약.md`에 부탁 문장 그대로(UTF-8) 저장하고 진도 `## 부탁문`에 `- 공고문_요약 (<오늘>)`을 더해요. "다음에 다른 공고문을 받으면 이 부탁을 그대로 쓰시면 돼요. 노션 '내 부탁문 모음'에도 붙여 두시면 좋아요."
