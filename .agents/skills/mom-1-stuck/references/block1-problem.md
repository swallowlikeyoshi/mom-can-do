# 블록 1: 오늘의 문제와 연습 파일

## 설명
- 월말 마감할 때 엑셀에 갑자기 `#VALUE!` 같은 글자가 뜨면 당황스럽죠. 지금까지는 아들에게 전화하는 수밖에 없었어요.
- 오늘은 **혼자 한 번 풀어보고, 그래도 안 되면 정리해서 보내는 순서**를 몸에 익혀요. 이게 몸에 붙으면 앞으로 어떤 강의를 하다 막혀도 혼자 이어갈 수 있어요. 그래서 제일 먼저 배워요.
- 연습용으로 **오류를 일부러 넣은 10월 장부**를 제가 만들어 드릴게요. 진짜 회사 파일이 아니라서 마음껏 만져도 괜찮아요.

## 해보기
(먼저 GPT가 [practice-ledger.md](practice-ledger.md)의 **만드는 스크립트**를 한 번에 실행해 파일을 만들어요. 만든 뒤 아래를 안내해요.)
1. 바탕화면의 **엄마연습** 폴더를 두 번 누르세요. 그러면 폴더가 열려요.
2. **연습1_오류있는장부** 파일을 두 번 누르세요. 그러면 엑셀로 10월 장부가 열려요.
3. 표를 천천히 훑어보세요. 이상한 글자가 보이는 칸이 **두 군데** 있어요.
4. 찾으셨으면 어느 칸인지 저한테 알려주세요. 칸 이름(예: "D12")을 모르시면 "합계 줄 출금 칸"처럼 말로 하셔도 돼요.

찾으신 두 칸을 말해 주시면 그걸로 '했어'예요.

## 확인
- 어머니가 두 곳(D12 `#VALUE!`, E2 `#REF!`)을 말씀하시면 통과예요. 한 곳만 찾으셨으면 "잘 찾으셨어요. 하나 더 있어요, 오른쪽 끝 줄을 보세요"로 짚어 드려요.
- 컴퓨터 사용이 켜져 있으면 화면을 직접 봐서 파일이 열려 있는지 확인해도 돼요. 오류 칸은 어머니가 찾으시게 두고 먼저 말하지 않아요.
- 통과하면: "이 두 오류를 다음 단계에서 **새 채팅**에서 풀어볼 거예요. 하나는 풀리고, 하나는 일부러 안 풀리게 만들었어요."
