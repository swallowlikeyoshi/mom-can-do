# 블록 2: 혼자 풀어보기

## 설명
- 이제 진짜 막혔을 때처럼 해볼게요. 실제로 일하다 막히면 이 선생님 창이 아니라 **아무 채팅**에서 물어보시게 될 거예요. 그래서 연습도 **새 채팅**에서 해요.
- 새 채팅에서 **"막혔어"**라고 쓰면 도움 스킬이 나와서 하나씩 물어보며 같이 풀어줘요. 화면은 GPT가 직접 볼 수 있어요.
- 먼저 합계 줄의 `#VALUE!`부터 풀어요.

## 해보기
1. 장부 파일은 열어 둔 채로, ChatGPT 앱 왼쪽 위 **새 채팅**을 누르세요. 그러면 빈 대화가 열려요.
2. 새 채팅에 **"막혔어. 엑셀 합계 칸에 #VALUE!가 떠"**라고 보내세요.
3. GPT가 묻는 말에 하나씩 답하고, 알려주는 대로 고쳐 보세요.
4. 고쳤으면 엑셀에서 **Ctrl + S**로 저장하세요. 그러면 고친 내용이 파일에 남아요. (csv 파일이면 "형식을 유지할까요?" 창이 뜰 수 있어요. 그땐 **예**를 누르세요.)
5. 왼쪽 대화 목록에서 이 **선생님 창**을 눌러 돌아오세요.

다 하시면 **'했어'** 라고 말해주세요.

## 확인
- [practice-ledger.md](practice-ledger.md)의 **확인 스크립트**를 한 번에 실행해 파일을 직접 열어 봐요.
- **D7이 숫자 120000이고 D12가 1817000**이면 통과: "출금 합계가 1,817,000원으로 제대로 나왔어요! 글자로 들어간 숫자 하나 때문이었죠."
- D7은 고쳤는데 D12가 비었거나 다른 값이면: 통과시키지 않고 그 한 가지만 짚어요 ("합계 칸이 비어 있어요"). 새 채팅에서 다시 "막혔어"로 물어보시라고 하고 "했어"를 요청해요.
- 저장을 안 하셨으면(파일은 그대로) "엑셀에서 Ctrl + S를 누르셨는지 한 번만 봐 주세요"라고 해요.
- 새 채팅을 못 찾으시면(블록 2 중간에 물어보셔도) 아래처럼 **번호 단계로** 다시 안내하고 "했어"를 요청하며 멈춰요. 컴퓨터 사용이 켜져 있으면 화면을 보고 버튼 위치를 어머니 화면 기준으로 짚어 드려요(대신 누르지는 않아요).
  1. 화면 왼쪽 위를 보세요. 연필 모양이나 "새 채팅" 글자가 있는 버튼이 있어요. 그러면 그걸 누르세요.
  2. 빈 대화가 열리면 거기서 "막혔어…"를 보내세요.
  3. 다 하면 왼쪽 대화 목록에서 이 선생님 창(제목에 "강의 1"이 들어간 것)을 눌러 돌아오세요.
  4. 왼쪽 목록이 안 보이면 왼쪽 위 줄 세 개 버튼을 먼저 누르세요.
  
  다 하시면 **'했어'** 라고 말해주세요.
