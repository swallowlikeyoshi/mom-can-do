# 블록 3: 안 풀리면 보내기

## 설명
- 이번엔 오른쪽 위 **전월 이월 칸의 `#REF!`**예요. 이건 지난달 마감 파일을 가리키던 수식이 깨진 거라, 원래 숫자가 이 파일 어디에도 없어요. **GPT도 못 고치는 문제**예요.
- 이런 건 오래 붙잡지 말고 **정리해서 아들에게 보내는 게** 제일 빨라요. 정리를 잘해서 보내면 아들도 전화 없이 바로 알아봐요.
- 아들이 귀찮아할까 걱정 마세요. 정리된 메시지가 전화보다 아들한테도 훨씬 편해요.

## 해보기
1. 아까 그 **새 채팅**으로 가세요 (왼쪽 목록에서 누르세요).
2. **"전월 이월 칸에 #REF!도 떠"**라고 보내고, 알려주는 대로 해보세요.
3. 두 번 해봐도 안 되면 **"도현이한테 보낼래"**라고 쓰세요. 그러면 GPT가 보낼 내용을 6줄로 정리해 줘요.
4. 정리된 글의 **복사** 버튼을 누르고, 카톡 아들 대화방에 **Ctrl + V**로 붙여서 보내세요. 오류 칸 캡처가 있으면 같이 보내세요(캡처 줄이 "없음"이어도 괜찮아요).
5. 이 선생님 창으로 돌아와서, 아까 그 6줄을 여기에도 붙여 주세요. (복사 버튼을 다시 누르거나, 글자를 마우스로 긁고 **Ctrl + C** → 여기서 **Ctrl + V**)

다 하시면 **'보냈어'** 라고 말해주세요.

## 확인
- 붙여 주신 글이 `[엄마 도움 요청]`으로 시작하고 `무슨 일 / 하려던 것 / 지금 상태 / 해본 것 / 캡처` 줄이 있으면 통과예요. "아주 잘 정리됐어요. 아들이 이것만 보고 바로 알 수 있겠어요."
- 빠진 줄이 있으면 그 줄만 짚어 드리고, 다음엔 새 채팅에 "○○ 줄도 넣어줘"라고 하시면 된다고 알려드려요. 이미 보내셨으면 그대로 통과예요.
- 아들 답장은 기다리지 않아요. "보냈어"면 끝이에요.
- 회사 보안 경고 같은 게 떴다면 그것도 같은 방법으로 보내면 된다고 한 줄 덧붙여요.
