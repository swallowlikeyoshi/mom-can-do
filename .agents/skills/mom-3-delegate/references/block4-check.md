# 블록 4: 검산하기

## 설명
- GPT는 아주 그럴듯하게 틀릴 때가 있어요. 그래서 **진짜 일은 꼭 검산**해요. 세 가지만 하면 돼요.
  1. **합계 대조**: 결과의 합계가 원자료 합계와 같은지 (이건 제가 직접 볼게요)
  2. **아무거나 3건**: 결과에서 아무 줄 3개를 골라 원자료와 눈으로 비교
  3. **틀릴 만한 곳 물어보기**: GPT에게 "틀릴 만한 곳 3개 짚어줘"

## 해보기
1. 제가 먼저 합계를 대조할게요. 잠깐 기다려 주세요.
2. 결과 파일에서 **아무 줄 3개**를 골라, 복사본 원자료에서 같은 거래처를 찾아 숫자가 같은지 보세요.
3. 아까 그 **새 채팅**에 **"이 결과에서 틀릴 만한 곳 3개 짚어줘"**라고 보내세요.
4. 2번 결과("3건 다 맞아" 같은)와 3번 답을 여기 붙여 주세요.

다 하시면 **'했어'** 라고 말해주세요.

## 확인
- **① 합계 대조는 선생님 창이 직접**: 결과 파일과 복사본을 열어(엑셀이면 COM으로 읽기 전용, csv면 `Get-Content -Encoding UTF8`) 같은 기준의 합계를 계산해 비교해요. 같으면 "합계가 원자료와 딱 맞아요(○○원)."
- 다르면 **통과시키지 않아요**: "○○원 차이가 나요." 새 채팅에 "합계가 원자료랑 ○○원 달라. 어디서 달라졌는지 찾아줘"라고 물어보게 하고, 고친 뒤 이 블록을 다시 해요.
- ②·③을 다 하셨으면 통과. ③에서 GPT가 짚은 곳 중 실제로 확인할 만한 게 있으면 하나만 같이 봐 드려요.
- 한 줄 정리: "진짜 일은 이 세 가지 검산을 꼭 해요. 특히 합계 대조요."
