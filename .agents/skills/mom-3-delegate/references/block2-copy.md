# 블록 2: 복사본 준비

## 설명
- 진짜 파일을 맡길 땐 **복사본**으로 해요. GPT가 잘못 고쳐도 원본은 멀쩡하게요. 중요한 서류를 복사해서 직원한테 주는 것과 같아요.
- 개인 정보(주민번호·계좌번호)만 없으면 회사 내용은 그대로 둬도 괜찮아요.

## 해보기
1. 그 일에 쓰는 **엑셀 파일**이 있는 폴더를 여세요.
2. 파일을 마우스 오른쪽 버튼으로 누르고 **복사**를 고르세요.
3. 바탕화면 **엄마연습** 폴더를 열고, 빈 곳에서 오른쪽 버튼 → **붙여넣기**를 고르세요. 그러면 똑같은 파일이 하나 생겨요.
4. 새로 생긴 파일 이름 끝에 **_복사본**을 붙여 주세요 (오른쪽 버튼 → 이름 바꾸기). 예: `10월_매출_복사본.xlsx`

다 하시면 **'했어'** 라고 말해주세요.

## 확인
- `엄마연습` 폴더에 `_복사본`이 붙은 파일이 있는지 직접 봐요. 있으면 통과: "원본은 그대로 있고, 이제 이 복사본으로 연습해요."
- 어머니가 원본 경로를 그대로 주시면(예: `D:\경리\...`): **여기서 멈춰요.** "원본은 GPT가 바꾸면 되돌리기 어려워요. 복사본부터 만들어요." 위 1~4를 다시 안내해요. 어머니가 "네가 복사해줘"라고 하시면 원본은 열지 않고 복사만 해서 `엄마연습`에 `_복사본` 이름으로 둬요.
- 파일에 주민번호·계좌번호가 보이면 한 줄만: "계좌번호는 다음부터 빼고 주시면 더 좋아요." 멈추지 않아요.
