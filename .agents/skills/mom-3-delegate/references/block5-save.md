# 블록 5: 나만의 스킬로 저장

## 설명
- 방금 잘 된 부탁을 **나만의 스킬**로 저장해 두면, 다음 달엔 긴 부탁 대신 **한마디**면 돼요. 아들이 만든 강의처럼, 어머니만의 작은 교재를 하나 만드는 거예요.
- 스킬 이름은 영어로 짧게 지어요. 예: 미수금 정리 → `my-misu-jeongri`. 이름은 제가 같이 정해 드릴게요.

## 해보기
1. 블록 3·4를 한 **그 새 채팅**으로 가세요.
2. **"방금 한 일을 내 스킬로 저장해줘. 이름은 my-○○로 해줘. 파일 이름이나 달은 그때그때 내가 말할게"**라고 보내세요. (○○ 이름은 제가 알려드린 걸로) 그래야 다음 달 파일로도 쓸 수 있어요.
3. 저장됐다고 하면, **새 채팅을 하나 더** 여세요.
4. 거기서 **"my-○○ 해줘. 이번엔 ○월 파일로"**처럼 한마디만 보내세요. 그러면 긴 부탁 없이 같은 일을 해요.

다 하시면 **'했어'** 라고 말해주세요.

## 확인
- 4번에서 같은 모양의 결과가 나왔으면 통과: "이제 다음 달엔 이 한마디면 돼요!" 진도 `## 부탁문`에 `- 스킬 my-○○: <일 이름> (<오늘>)`을 적어요.
- **스킬 저장이 안 되면**("이 환경에서는 만들 수 없어요" 등): "괜찮아요, 부탁문으로 저장해도 거의 똑같이 쓸 수 있어요." 블록 3의 부탁 문장에서 **달·파일 이름은 "○월 파일"처럼 빈칸으로 바꿔서** 문서 폴더 `엄마강의\부탁문\<일 이름>.md`(UTF-8)로 저장하고, 새 채팅에 그 내용을 붙여 넣어 같은 결과가 나오는지 시험하게 해요. 진도 `## 부탁문`에 `- 부탁문 <일 이름> (<오늘>)`을 적어요.
- 강의 4에서 이 스킬(또는 부탁문)을 **정해진 때 알아서 돌게** 할 거라고 한 줄 예고해요.
