# 블록 3: 맡기기

## 설명
- 강의 2에서 배운 **네 가지**(상황·원하는 결과·예시·모르면 물어봐줘)로 부탁해요. 숫자를 다루는 일이라 모델은 **Sol**(없으면 Terra + 생각하기)로 해요.
- 실습은 **새 채팅**에서 해요.

## 해보기
1. **새 채팅**을 열고 모델을 **Sol**로 바꾸세요. 그러면 입력창 근처에 Sol이 보여요.
2. 아래 틀을 채워서 보내세요. 파일 이름은 어머니 파일로 바꿔요.
   ```
   (상황) 바탕화면 엄마연습 폴더의 ○○_복사본.xlsx는 우리 회사 ○월 자료야.
   (원하는 결과) ○○를 정리해서 같은 폴더에 ○○정리.xlsx로 만들어줘.
   (예시) | 거래처 | ○○ | ○○ | 합계 | 모양으로.
   (모르면 물어봐줘) 헷갈리는 게 있으면 만들기 전에 먼저 물어봐줘.
   ```
3. GPT가 되물으면 답해 주세요.
4. 결과 파일이 생겼다고 하면, 엄마연습 폴더에서 열어 보세요.

다 하시면 **'했어'** 라고 말해주세요.
