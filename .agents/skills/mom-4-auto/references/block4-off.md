# 블록 4: 끄고 지우기

## 설명
- 알람도 필요 없어지면 끄죠. 예약도 **끄는 법, 지우는 법**을 알아야 마음 편히 써요.
- 아까 만든 **시험 예약**을 지워 볼게요. 진짜 예약은 그대로 둬요.

## 해보기
(먼저 GPT가 컴퓨터 사용으로 예약 화면을 **직접 보고**, 실제로 보이는 버튼·칸 이름으로 아래 단계를 바꿔서 안내해요. 아래 괄호 속 이름은 예시일 뿐이에요. 화면에서 확인하지 못한 버튼·칸은 말하지 않고, "화면에 보이는 대로 알려주세요"라고 어머니께 여쭤봐요. 마우스를 움직이기 전엔 손 떼 달라고 말해요.)
1. 예약 목록에서 **시험 예약**(5분 뒤로 걸었던 것)을 찾으세요. 시험을 두 번 하셨으면 둘 다예요.
2. 그 줄에서 메뉴를 여는 곳(예: ⋯ 버튼, 마우스 오른쪽 버튼)을 누르세요. 그러면 끄기·지우기 같은 선택지가 나와요.
3. 지우는 선택지를 누르세요. 그러면 목록에서 사라져요.
4. **엄마-○○** 진짜 예약은 남아 있는지 보세요.

다 하시면 **'했어'** 라고 말해주세요.

## 확인
- 예약 목록을 직접 봐서 시험 예약이 없고 `엄마-` 예약만 남았으면 통과.
- 한 줄 정리: "잠깐 멈추고 싶을 땐 지우지 말고 **끄기**만 하셔도 돼요."
