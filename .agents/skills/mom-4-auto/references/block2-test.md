# 블록 2: 5분 뒤로 시험하기

## 설명
- 진짜로 걸기 전에 **5분 뒤에 한 번만** 돌게 해서 정말 되는지 봐요. 알람도 처음엔 1분 뒤로 맞춰서 울리는지 보잖아요.
- 시험 결과 파일은 이름 끝에 `_시험`을 붙여서 진짜와 헷갈리지 않게 해요.

## 해보기
(먼저 GPT가 컴퓨터 사용으로 예약 화면을 **직접 보고**, 실제로 보이는 버튼·칸 이름으로 아래 단계를 바꿔서 안내해요. 아래 괄호 속 이름은 예시일 뿐이에요. 화면에서 확인하지 못한 버튼·칸은 말하지 않고, "화면에 보이는 대로 알려주세요"라고 어머니께 여쭤봐요. 마우스를 움직이기 전엔 손 떼 달라고 말해요.)
1. 예약 화면에서 새 예약을 만드는 버튼(예: "새 예약", +)을 누르세요. 그러면 내용을 쓰는 화면이 나와요.
2. 할 일을 쓰는 칸에 제가 드리는 문장(**<할 일 문장>** + "결과 파일 이름 끝에 _시험도 붙여줘")을 복사해서 붙이세요. 이름 칸이 있으면 "엄마-시험"이라고 쓰세요.
3. 시간은 **지금부터 5분 뒤, 한 번만**으로 맞추세요. 고르는 곳은 제가 화면을 보고 짚어 드릴게요.
4. 저장하세요. 그러면 예약 목록에 새 줄이 생겨요.

그다음엔 확실하지 않으니 **ChatGPT 앱은 켜 둔 채로** 5분 기다려 주세요. 다른 일 하셔도 돼요. 5분 뒤 바탕화면 **엄마연습** 폴더에 `_시험` 파일이 생겼는지 보세요.

다 하시면 **'했어'** 라고 말해주세요.

## 확인
- `엄마연습` 폴더에 `_시험` 결과 파일이 생겼는지 직접 봐요. 생겼으면 통과: "5분 뒤에 GPT가 혼자 해 놨어요!" 결과를 강의 3처럼 합계만 한 번 대조해 줘요.
- 안 생겼으면 통과시키지 않아요. 이유를 하나만 짚어요:
  - 앱을 닫으셨으면: "앱이 닫혀 있어서 안 돌았을 수 있어요. 앱을 켜 둔 채로 다시 5분 뒤로 걸어 볼게요." 아까 만든 시험 예약은 지우지 말고 그대로 두셔도 돼요(블록 4에서 같이 지워요). 다시 걸어서 **켜 둔 채로는 돌았으면** 그때 진도 맨 아래에 `메모: 예약 작업은 앱이 켜져 있어야 함 (<오늘> 확인)`을 적어요. 돌기 전엔 적지 않아요.
  - 예약 목록에 그 예약이 없으면 저장이 안 된 거예요 → 1~4 다시.
  - 예약은 있는데 파일이 없으면: 컴퓨터 사용으로 그 예약의 **실행 기록이나 답**을 봐요(GPT가 "어느 파일이요?"처럼 묻고 멈췄는지 등). 본 것만 말하고, 원인이 문장이면 할 일 문장을 고쳐 다시 걸어요.
- 확인된 것만 말해요. 확인 안 된 건("PC가 잠겨도 도는지") "아직 몰라요, 다음에 보면 알 수 있어요"라고 해요.
