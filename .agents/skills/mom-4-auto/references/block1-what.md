# 블록 1: 예약 작업이 뭔지

## 설명
- **예약 작업**은 알람 같은 거예요. 휴대폰 알람을 맞춰 두면 그 시간에 울리듯이, "매달 말일 오후 4시에 미수금 정리해줘"라고 맞춰 두면 **그때 GPT가 알아서** 해 둬요.
- 강의 3에서 저장한 일을 이걸로 걸어 두면, 어머니는 결과만 확인하시면 돼요.
- 앱마다 이 기능의 이름이 달라요(영어 화면이면 Scheduled tasks, Automations 같은 이름). 제가 먼저 화면에서 찾아볼게요.

## 해보기
(먼저 GPT가 진도 `## 부탁문`에서 강의 3의 스킬/부탁문 이름을 읽어요. 없으면 대체 일 "바탕화면 엄마연습 폴더의 파일 목록을 목록.txt로 정리"로 해요. 그다음 컴퓨터 사용으로 앱의 왼쪽 메뉴·설정·입력창 옆 메뉴에서 예약 기능을 찾아요. 마우스를 움직이기 전엔 손 떼 달라고 말해요.)
- **찾았으면**: 
  1. 제가 짚어 드린 **○○ 메뉴**(화면에 보이는 이름)를 눌러 보세요. 그러면 예약 목록 화면이 열려요.
  2. 지금은 둘러보기만 하세요. 아직 아무것도 만들지 않아요.
- **못 찾았으면**: 새 채팅에서 "5분 뒤에 '안녕'이라고 알려줘"를 보내 보시게 해요. 예약이 안 된다는 답이면 **대안 경로**로 가요 (아래 확인).

다 하시면 **'했어'** 라고 말해주세요.

## 확인
- 예약 화면이 열렸으면 통과. 진도 맨 아래에 `화면 이름: 예약 작업 = <메뉴 이름>`을 적어요.
- **예약 기능이 없으면 (대안 경로)**: 진도에 `화면 이름: 예약 작업 = 없음`을 적고, 블록 2~4 대신 아래를 해요. 이걸 마치면 강의 4를 마친 거예요.
  1. "이 앱에는 아직 예약 기능이 없어요. 대신 **알림 + 한마디** 습관으로 거의 똑같이 할 수 있어요."
  2. 휴대폰 달력이나 회사 PC의 Outlook 달력에 **반복 일정**을 만들게 해요: 제목 "GPT: my-○○ 한마디", 반복 = 어머니가 고른 주기 (언제로 할지 먼저 여쭤봐요).
  3. 알림이 오면 ChatGPT 앱에서 **새 채팅**을 열고 **"my-○○ 해줘"** 한마디 → 결과 검산(강의 3의 세 가지).
  4. 지금 한 번 연습: 새 채팅에 한마디를 보내 결과 파일이 생기는지 확인하고 "했어"를 받아요.
