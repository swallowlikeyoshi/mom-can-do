# 블록 1: 예약 작업이 뭔지

## 설명
- **예약 작업**은 알람 같은 거예요. 휴대폰 알람을 맞춰 두면 그 시간에 울리듯이, "매달 말일 오후 4시에 미수금 정리해줘"라고 맞춰 두면 **그때 GPT가 알아서** 해 둬요.
- 강의 3에서 저장한 일을 이걸로 걸어 두면, 어머니는 결과만 확인하시면 돼요.
- 앱마다 이 기능의 이름이 달라요(영어 화면이면 Scheduled tasks, Automations 같은 이름). 제가 먼저 화면에서 찾아볼게요.

## 해보기
(먼저 GPT가 컴퓨터 사용으로 앱의 왼쪽 메뉴·설정·입력창 옆 메뉴에서 예약 기능을 찾아요. 마우스를 움직이기 전엔 손 떼 달라고 말해요. **예약 기능이 있는지는 이 화면 확인으로만 정해요.** 새 채팅에 "5분 뒤에 알려줘"를 보내 보게 하지 않아요 (GPT가 말로만 "알려드릴게요"라고 하고 실제로는 예약하지 않을 수 있어서요). 화면이 불확실하면 어머니께 캡처를 부탁해요.)
- **찾았으면**:
  1. 제가 짚어 드린 메뉴(화면에 보이는 이름)를 눌러 보세요. 
  2. 지금은 둘러보기만 하세요. 아직 아무것도 만들지 않아요.
- **못 찾았으면**: "이 앱 화면에는 예약 기능이 안 보여요. 대신 알림 + 한마디로 거의 똑같이 할 수 있어요"라고 말하고, 아래 **대안 경로 1턴**으로 바로 가요.

찾았을 때는 다 하시면 **'했어'** 라고 말해주세요.

## 확인
- 예약 화면이 열렸으면 통과. 진도 맨 아래에 `화면 이름: 예약 작업 = <메뉴 이름>`을 적어요.

## 대안 경로 (예약 기능이 없을 때)
진도 맨 아래에 `화면 이름: 예약 작업 = 없음`을 적고, 블록 2~4 대신 아래 세 턴을 해요. 이걸 마치면 강의 4를 마친 거예요. 턴마다 마지막 요청에서 멈춰요.
- **1턴: 언제** — "이 일을 보통 언제 하세요? 예를 들면 매달 말일 오후 4시, 매주 월요일 아침 9시처럼요. 정하신 때를 말해 주세요."
- **2턴: 반복 알림 만들기** — 회사 PC의 Outlook 달력이 있으면 그걸로(컴퓨터 사용으로 화면을 보고 본 이름으로 안내), 없으면 휴대폰 달력으로:
  1. 달력을 여세요.
  2. 정하신 날짜·시간에 새 일정을 만드세요.
  3. 제목은 **"GPT 한마디"**로 쓰세요.
  4. 반복을 정하신 주기로 맞추고 저장하세요.
  
  다 하시면 **'했어'** 라고 말해주세요. → 확인: Outlook이면 화면으로 반복 일정을 직접 보고, 휴대폰이면 캡처나 "반복으로 저장했어"를 받아요.
- **3턴: 한마디 연습** — "알림이 오면 이렇게 하시면 돼요. 지금 한 번 해볼게요."
  1. ChatGPT 앱에서 **새 채팅**을 여세요.
  2. 제가 드리는 **<할 일 문장>**을 복사해서 보내세요.
  3. 엄마연습 폴더에 결과 파일이 생겼는지 보세요.
  
  다 하시면 **'했어'** 라고 말해주세요. → 확인: 결과 파일이 생겼는지 직접 보고, 합계만 한 번 대조해요. 알림을 끄거나 지우는 법(달력에서 그 일정 열기 → 삭제)도 한 줄로 알려드려요.
